============================================================
PVS-SPECIFIC HARD BOUNDARIES
============================================================

`pavis-pvs` MUST:
- define the `.pvs` binary artifact format
- define headers, magic bytes, versioning, and layout
- perform integrity and safety validation (lengths, checksums, version checks)
- safely deserialize / archive data (e.g., rkyv-based)

`pavis-pvs` MUST NOT:
- perform business or routing semantics
- apply defaults or policy decisions
- assume runtime behavior or environment
- perform network or filesystem I/O beyond reading raw bytes when explicitly required
- parse YAML, xDS, or high-level config formats

The artifact MUST be treatable as OPAQUE by relay and runtime
after validation (i.e., no semantic interpretation required downstream).
