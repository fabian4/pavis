# Benchmark Evidence Harness

This directory contains the scripts and fixtures used to reproduce the runtime capability measurements described in the engineering thesis.

See:
- [Methodology](../docs/benchmarks/methodology.md) — defines the measurements, workloads, and acceptance criteria for the frozen data plane.
- [Running Benchmarks](../docs/benchmarks/running.md) — describes how to reproduce the measurements locally or in CI.

Benchmark artifacts are written to `bench/output/` for inspection.
