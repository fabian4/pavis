# Pavis E2E

This crate contains end-to-end tests for both Pavis and Relay.

Run modes:
- Pavis E2E:
  - Binary: `make e2e-pavis-binary`
  - Docker: `make e2e-pavis-docker`
- Relay E2E:
  - Binary: `make e2e-relay-binary`
  - Docker: `make e2e-relay-docker`

Case lists:
- Pavis cases: `crates/pavis-e2e/CASES_PAVIS.md`
- Relay cases: `crates/pavis-e2e/CASES_RELAY.md`
